# Portfolio Content

This document defines the public content direction for the portfolio site.

## Positioning

YB Kim is presented as a frontend-specialized full-stack web developer: strongest
at frontend implementation, with enough API, deployment, and documentation
literacy to collaborate across the product surface.

## Core Message

Build web products with clear UI, typed implementation, maintainable structure,
and enough adjacent technical understanding to carry work from planning to
release without losing public-information safety.

## Suggested Sections

| Section    | Purpose                                  |
| ---------- | ---------------------------------------- |
| Intro      | State positioning and job-seeking status |
| Projects   | Present public project summaries         |
| Skills     | Connect tools to delivery responsibility |
| Process    | Show planning, documentation, and checks |
| Repository | Invite technical review of this project  |
| Contact    | Provide a safe recruiter next action     |

## Tone

- Clear, direct, and evidence-backed.
- Confident without exaggerating private work.
- Short enough for recruiters, concrete enough for engineers.

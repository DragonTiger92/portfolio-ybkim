# Roadmap

The roadmap uses phases as scope groupings, not fixed calendar promises.

| Phase    | Name                       | Status      | Goal                                      |
| -------- | -------------------------- | ----------- | ----------------------------------------- |
| `PH-001` | Documentation Baseline     | In Progress | Establish public docs, ADRs, and SBOM     |
| `PH-002` | Portfolio Content Baseline | Planned     | Finalize public-safe content and projects |
| `PH-003` | Static Site Implementation | Draft       | Replace the Vite scaffold with portfolio  |
| `PH-004` | Quality And Accessibility  | Draft       | Polish accessibility, performance, checks |
| `PH-005` | Deployment And Review      | Draft       | Deploy through GitHub Pages and review    |

## Phase Notes

- `PH-001` makes the repository readable before deeper implementation.
- `PH-002` turns career and project material into concise public copy.
- `PH-003` focuses on the actual static site experience.
- `PH-004` validates the site as a polished web artifact.
- `PH-005` confirms that the deployed result matches the repository docs.

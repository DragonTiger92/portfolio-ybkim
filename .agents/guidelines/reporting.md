# Reporting Guidelines

When reporting work:

- Summarize what changed.
- List files changed.
- Mention checks run.
- Mention checks not run and why.
- Mention assumptions clearly.
- Keep explanations concise but complete.
- Mention a task-created process, browser tab, or temporary report only when it
  remains active, and explain why it was retained.

Preferred completion format:

```txt
Changed:
- ...

Checked:
- ...

Notes:
- ...
```

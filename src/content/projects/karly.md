## 프로젝트 맥락

프레임워크보다 웹 기본기와 팀 협업을 먼저 검증한 프로젝트로, 상품 탐색 흐름과 UI 구조를 직접
구현하며 접근 가능한 마크업과 유지보수 가능한 스타일 구조를 실습했습니다.

## 기여 경계

상품 목록과 상품 상세 페이지를 맡아 의미가 드러나는 HTML 구조, CSS 변수 기반 스타일링, DOM 상호작용을
구현하고 결과 발표에 참여했습니다.

## 구현 접근

HTML 구조가 콘텐츠 의미를 드러내도록 구성하고, 반복되는 색상과 간격은 CSS 변수로 관리했습니다.
Vanilla JavaScript로 목록과 상세 흐름을 연결하면서 정해진 역할과 일정 안에서 팀 결과를 통합했습니다.

## 결과

공개 저장소와 배포 데모를 통해 담당 화면과 팀 결과를 함께 검토할 수 있습니다. 브라우저 기본 기능과
DOM을 직접 다룬 경험은 이후 컴포넌트 구조와 접근성을 판단하는 기반이 되었습니다.
